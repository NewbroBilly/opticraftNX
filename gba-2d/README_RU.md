# OptiCraft 2D для Game Boy Advance

Независимый прототип двухмерной песочницы для GBA. Это отдельная игра на C/libgba; Java-клиент и код Switch-порта не используются.

## Уже есть

- процедурная карта 128 × 64 блока: трава, земля, камень, пещеры и деревья;
- движение, прыжок, столкновения и камера;
- добыча блока перед персонажем и установка выбранного блока;
- три слота ресурсов: земля, камень и дерево;
- ручное сохранение мира и позиции игрока в SRAM кнопкой Start;
- графика из простых фигур, без внешних файлов.

## Сборка

Нужны devkitPro, devkitARM и пакет libgba. В окружении devkitPro:

```sh
cd gba-2d
make
```

Результат: `opticraft_2d_gba.gba`. Для запуска откройте файл в эмуляторе GBA или скопируйте на flash-картридж. Сохранение использует 32 КБ SRAM-карту картриджа.

## Управление

| Кнопка | Действие |
| --- | --- |
| D-pad влево/вправо | Ходьба |
| D-pad вверх | Прыжок |
| A | Добыть блок перед персонажем |
| B | Поставить выбранный блок |
| L / R | Выбрать слот: земля, камень, дерево |
| Start | Сохранить мир |

Это первый играбельный срез: инвентарь пока ограничен тремя счётчиками, крафта и мобов нет.
