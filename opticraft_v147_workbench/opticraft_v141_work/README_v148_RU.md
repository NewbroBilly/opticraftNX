# OptiCraft Switch v148

Host checkpoint исходного клиента Minecraft Java 1.2.5 с исправлениями GL color mask и правила растеризации общей границы треугольников.

Подробный результат и ограничения: [REPORT_v148_RENDERER_FIXES_RU.md](REPORT_v148_RENDERER_FIXES_RU.md).

Этот архив не является полноценным Switch NRO и не подтверждает запуск на физическом устройстве. Меню появляется в host probe, однако графические артефакты и остановка по instruction budget сохраняются.
