# OptiCraft Switch v143 — раскладка контроллера

## Что реализовано в исходниках

- Левый аналоговый стик формирует W/A/S/D с deadzone.
- L3 формирует Left Control как зарезервированную клавишу спринта.
- Правый аналоговый стик двигает указатель/камеру через существующий bridge; R3 формирует F5.
- A → Space, B → Q (выброс), X → E (инвентарь), Y → C (зарезервированный shortcut к меню крафта).
- Plus → Escape (пауза), Minus → Tab (список игроков).
- ZR → левая кнопка мыши (атака/разрушение), ZL → правая (использование/установка).
- L/R формируют колесо LWJGL (+120/-120) для переключения хотбара.
- D-pad Up → F1, Down → Left Shift (sneak), Left → F3, Right → T (чат).
- Добавлена передача wheel events в Java `SwitchInputImplementation`.
- Обновлены C++ и JNI/Java тесты раскладки.

## Ограничения и важные оговорки

Это реализация host-side / платформенного адаптера ввода и проверка преобразования событий. В текущей версии не подтверждено, что Horizon main loop уже вызывает `SwitchInputImplementation.pump()` каждый кадр в собранной игре; подключение этого вызова к реальному игровому циклу остаётся отдельным интеграционным шагом.

Оригинальный Minecraft Java 1.2.5 не имеет штатной отдельной клавиши спринта и глобальной клавиши меню крафта. Поэтому L3 пока выдаёт Left Control как зарезервированный сигнал для будущей игровой логики спринта, а Y выдаёт C как зарезервированный shortcut. Само поведение спринта и открытие отдельного меню крафта требуют изменений игровой логики и здесь не заявляются как завершённые.

Проверки выполнены на host. NRO не собирался; физическая Nintendo Switch и реальные Joy-Con/Pro Controller не проверялись.
